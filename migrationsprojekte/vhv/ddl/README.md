# Schema-Beschreibung VHV

Hier die DDL der Altdatenbank ablegen (`*.ddl` oder `*.sql`, DB2 for z/OS), z. B. als Export mit
`db2look`, IBM Data Studio oder DBeaver. Mit `LABEL ON`/`COMMENT ON` exportieren, damit die KI die fachliche
Bedeutung der Spalten kennt. Mehrere Dateien und Unterordner sind möglich.
